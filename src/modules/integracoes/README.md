# Integrações Module

## Descrição
Módulo de Integrações com Sistemas Externos.

## Estrutura
- **types/** - Interfaces e tipos TypeScript
- **repositories/** - Camada de acesso a dados
- **services/** - Lógica de negócio
- **actions/** - Server Actions (Next.js)
- **components/** - Componentes React
