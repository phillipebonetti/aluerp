🎯 REGRAS DE NEGÓCIO DOCUMENTADAS
═══════════════════════════════════════════════════════════════════════════

1. Empresa
   • CNPJ válido
   • Plano não pode fazer downgrade
   • Soft delete cascata

2. Acesso (RBAC)
   • Permissão requerida para ação
   • Primeiro membro é Owner
   • Invites criam com status INVITED

3. Clientes
   • Documento (CPF/CNPJ) validado
   • Endereço primário obrigatório
   • Não pode deletar com projects/quotes

4. Fornecedores
   • Tipos específicos (material, service, labor)
   • Contato primário obrigatório

5. Obras
   • Status transitions (planning → progress → complete)
   • Projeto não muda de cliente
   • Custo total calculado automaticamente

6. Orçamentos
   • Numeração única por company
   • Total = SUM(items) - SUM(discounts)
   • Versionamento quando editado

7. Financeiro
   • Balance = income - expense
   • Transaction não pode ser editado
   • Status OVERDUE automático

8. Auditoria
   • Logging obrigatório
   • Registro de mudanças (antes/depois)

🚀 COMO COMEÇAR
═══════════════════════════════════════════════════════════════════════════

1. Setup Supabase:
   $ DATABASE_URL=postgresql://... pnpm exec prisma validate

2. Fazer Migration:
   $ pnpm exec prisma migrate dev --name init

3. Gerar Types:
   $ pnpm exec prisma generate

4. Rodar Tests:
   $ pnpm exec tsc --noEmit
   $ pnpm test

5. Verificar Studio:
   $ pnpm exec prisma studio
